#+TITLE: gb-camera-dumper-rs

This is a work in progress project that is meant to provide a simple CLI tool to
dump data from a Game Boy Camera through a GBxCart RW.

* Proof of concept

The current proof of concept auto-detects a GBxCart RW on the available serial
ports, checks that the inserted cartridge ROM title is one of these supported
Game Boy Camera titles, dumps the full 128 KiB SRAM image to a file, and
exports every undeleted photo as a PNG into =gb-camera-photos/= next to the
SRAM dump:

#+begin_example
GAMEBOYCAMERA
POCKETCAMERA
#+end_example

#+begin_example
cargo run -- dump-sram --output gb-camera.sav
#+end_example

You can customize exported PNG names with =--filename-template=. The supported
fields are =year=, =month=, =day=, =hour24=, =hour12=, =minute=, =sequential=
and =slot=. Add a width such as =:02= to zero-pad numeric fields.

#+begin_example
cargo run -- dump-sram \
  --filename-template 'photo-{year}{month:02}{day:02}_{hour24:02}{minute:02}_{sequential:02}_slot-{slot:02}.png'
#+end_example

For now, the PNG export directory is wiped clean on each run so test dumps do
not leave stale images behind.

To inspect the serial ports and USB metadata first:

#+begin_example
cargo run -- ports
#+end_example

The implementation is based on the GBxCart RW v1.x serial protocol used by the
upstream insideGadgets tools: single-byte probe commands such as =C=, =h= and
=V=, hex-with-NUL numeric commands such as =A= and =B=, and 64-byte streaming
ROM/RAM reads controlled with =R=, =1= and =0=.

* Configuration

An example config file is included at config.yaml.example in the repository
root. Copy it to $XDG_CONFIG_HOME/gb-camera-dumper/config.yaml or
$HOME/.gb-camera-dumper-config.yaml and edit as needed.
